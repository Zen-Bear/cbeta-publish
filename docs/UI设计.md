# CBETA 发布程序 — UI 设计

> 2026-09-17 合并整理：吸收旧《UI设计.md》与《链路B-UI设计.md》，去重并同步实现。
> 总方案见《设计总案.md》，跨仓调用契约见《链路B-设计契约.md》。

## 1. 整体布局

单窗三栏 + 底部页签，路径「浏览 → 勾选 → 工作区 → 右栏丛书 → 发布」：

```
┌──────────────────────────────────────────────────────────────────┐
│ 设置…   自制书籍   视图                                            │
├──────────────┬──────────────────────┬──────────────────────────────┤
│ 左栏         │ 中栏（工作区）        │ 右栏（丛书）                  │
│ 视图单选     │ 书籍列表              │ 丛书下拉 / 分类筛选           │
│ 搜索+过滤    │ 排序 全选/不选/…      │ 格式 / 来源 / 预设 / 生成     │
│ 目录树/工作区│                       │ 发布按钮 / E书目录            │
│              │                       │ 书单（拖拽排序）              │
├──────────────┴──────────────────────┴──────────────────────────────┤
│ 页签：书籍信息 | 丛书信息 | E书目录                                  │
└──────────────────────────────────────────────────────────────────┘
```

- **视图切换**：菜单「视图 → 三栏（含选书区）/ 二栏（隐藏选书区）」单选。
- 二栏时「工作区」与「目录区」二选一显示（搜索行按钮切换，带计数）。

## 2. 左栏（导航 / 搜索 / 工作区）

- **视图**为单选按钮（部类/三藏/刊本/朝代/作者/丛书；`_RadioBar`，接口仿 QComboBox）。
- 二级过滤随视图显隐：部类过滤（三藏/部类）、刊本过滤、标签筛选、朝代/作者排序。
- **搜索**：经名/作者/经号，英文大小写不敏感，繁简/异体变体；覆盖所有视图。
- **目录树配色**：书叶（单本）文字黑色，分组节点沿用主题色；选中/悬停与中栏列表
  完全一致（选中 `#bbdefb`、悬停 `#fff3c4`、选中+悬停 `#90caf9`）。
- **工作区**：唯一内存书单（与中栏同一份数据，两个视图）；搜索行按钮：`✕ 清除`、
  `＋`（搜索结果加入工作区）、`工作区（N）`（与目录区切换）。
- 交互：目录树拖入工作区/右栏、双击书加入（三栏→工作区；二栏→右栏）、双击丛书/作者追加其书目。

## 3. 中栏（工作区）

- 书籍列表（`_refresh_ws_views` 渲染，与左栏工作区同一数据）。
- 排序：原始顺序（默认）/ 经号 / 经名；全选/全不选/加入已选/全删。
- 点书 → 右下「书籍信息」页签显示；双击书 → 加入右栏并移出工作区（移动语义）。

## 4. 右栏（丛书）

```
格式：[☑ pdf] [☑ epub] [☑ docx]      （其它格式用ZIP/导出）
来源：○ 官方  ○ 自制   预设：[ 我的配置 ▾ ] [调整…]   （预设仅来源=自制时启用）
发布：[合并] [ZIP] [导出] [下载/更新]                 （来源=自制时改为 [自制] [重制]）
```

- **格式**：pdf/epub/docx 勾选（docx 默认勾选，是 xml2pdf 主要特点）；
  **合并只取其中 pdf/epub**（仅勾 docx 点合并会提示）；docx 走 ZIP/导出/校验/打开。
  勾选职责（各框有 tooltip）＝用于「自制生成/下载/校验」与书单「已有」标志；
  其它格式走 ZIP/导出弹窗。
- **来源**：互斥，读写全局 `default_source`（`official`/`xml`），改动即落盘。
- **预设**：紧接「自制」单选右侧；xml2pdf 仓库 `presets/` 下 stem ＋「出厂默认」；改动写回全局。
  `[调整…]` 打开上游 `XmlOptionsDialog`：点「确定」＝写成**临时预设**、
  本次立即生效并强制重生成；随后问「保存为预设？（覆盖/另存为/不保存）」，
  选不保存即改选预设/退出时丢弃。临时生效时预设行显示「预设(本次):」。
- **生成策略**：**合并/ZIP/导出恒为「仅缺」**（已有书籍直接复用、只补缺）；
  需整体重生成先点 `[重制]`。不用 mtime/哈希推断过期。
- **发布行**：来源=官方显示 `[下载/更新]`；来源=自制显示 `[自制]`（补缺）、
  `[重制]`（全部重生成）。**设置「自制书籍」=校验时，这两个按钮生成后逐本校验、
  仅通过项导入**（见 §8）；=无校验时只生成。
- **书单**：
  - 格式图标：**双击打开**该格式（不存在无反应）；tooltip：存在=「双击打开」、
    缺=「XX未下载」。**双击书名**：打开存在的格式（先 PDF，再 EPUB，再 DOCX）。
  - 行内复选框为右栏本地标记（供移除收集），与中栏勾选独立。
  - 拖拽排序；拖出到左栏 = 移除（进工作区）。右栏不做分组显示。
- `source`/`work_sources`/`xml_options` 只读兼容，不再写入、不参与决策。

## 5. 右下页签

- **书籍信息**：点书显示（经号/经名/作者/卷/文件）。下载/自制完成后列出本次产物；
  **校验（自制/重制=校验、导入校验通过E书）后列出逐本/逐格式结果**——
  已入库、未入库（含"未入 epub"这类部分通过信息，警示色）、未判定，附
  验证输出目录/已入库目录链接（可点开），显示自动回到第一行。
- **丛书信息**：丛书名/分类/部数/最后发布/标签/产物链接（可点击）；合并/ZIP/导出
  成功后切到本页签。
- **E书目录**：`官方`/`自制`/`丛书` 三个可点链接（点击打开对应目录，悬停看全路径，
  右侧显示完整路径；设置变更后刷新）。

## 6. 菜单

- 「设置…」（菜单栏直达，`Ctrl+,`）。
- 「自制书籍」：
  - `xml2pdf 独立窗…`：手动全选项工作台（子进程）。
  - `导入校验通过E书…`：手动导入——优先读当前丛书的 `verify_dir/<丛书>/`；
    无报告时**弹目录选择**，可指向独立窗的输出目录（其中含
    `*_verify_report.txt` 或 `（验证）/report.txt` 即可）。
  - `独立窗输出与导入规则…`：只读弹窗，内容同《链路B-设计契约.md》§9。
- 「视图」：三栏/二栏单选。

> 「校验重制」已从菜单移到**右栏发布行**按钮（来源=自制时显示）。

## 7. 合并 / ZIP / 导出 / 校验（交互变化点）

1. 点「合并」→ 空书/空白改名检查（来源、预设取右栏；自制生成恒「仅缺」）；
   分册按设置 `merge.mode`：
   - `不分册/按刊本册/按目录` → 直接按该模式合并；
   - `合并时选择` → **弹「合并设置（分册）」**：模式三选一 + 深度 1–5（默认 2）+ 预览
     （分组→部数→文件名），选择记忆（`merge.ask_last`）供下次默认；取消则中止。
   - 命名：路径段清洗后用 `_` 连接（如 `太虛大師全書_法藏.pdf`、
     `01 阿含部類_長阿含經.pdf`）；段内**全角 `／` 保留**（如 `中觀部／疏`），
     经号（`T30a`/`T1564-67`/`K41`/`X46,54`…）与 `etc.` 去掉，
     作者等正文保留（如 `二諦義 (3卷)【隋 吉藏撰】`）；未命中 → `未分册` / `未歸類`（置末）。
2. 点「ZIP」/「导出」→ 弹「选择打包格式」（官方 7 种、自制 3 种；预选＝设置里对应来源的默认格式）。
   目录型只打包不合并：ZIP 按 `部/相对路径` 写入 `{丛书名}_{fmt}.zip`，
   导出整树拷贝到 `{target}/{work}/`。
3. 来源=官方且缺书 → 弹「是否先下载？」；来源=自制缺则生成（已有复用，不自动重生成）。
4. 进度窗（`_make_progress`，复用）：可滚动日志+进度条+取消；前置下载无错时 3 秒自动关闭续跑。
5. **自制/重制（设置=校验时）**：进度窗逐本「生成并校验 X …通过/部分通过/未通过」，
   跑完**逐格式**自动导入（通过项入库，未通过格式不拖累，如 docx 过、epub 没过则只入 docx）；
   总结「校验完成 x/y／验证输出目录：<可点目录>；已自动导入 n 部；未通过/未入库（警示色）」
   （见《链路B-设计契约.md》§5）。

## 8. 设置对话框

按钮语义：`确定`＝仅本次运行生效（不写盘）；`保存`＝写 `config/app.json`；
`取消`＝本次改动不生效；`恢复默认`/`恢复原始` 只载入对话框，仍需 `确定`/`保存`。

页签：
- **数据/输出**：目录数据/丛书数据/官方电子书/丛书输出目录（默认 `collections_books`，
  全路径，相对按工程根解析）；以及组框**「E书默认来源和格式」**：
  - `默认E书来源`：单选 官方/自制（`default_source`），自制后附说明
    「（PDF/DOCX 优化，其它格式推荐官方）」。
  - `合并默认格式`：pdf/epub（`default_formats.merge`，初始化右栏格式勾选）。
  - `官方 ZIP/导出默认`：官方全 7 种（`txt_notes` 显示为「txt含注释」），
    默认 `pdf/epub/html/docx/txt`（去掉 odt/txt_notes）。
  - `自制 ZIP/导出默认`：pdf/docx/epub，默认 `pdf/docx`（不勾 epub）。
  - 两组分别作为 ZIP/导出弹窗按来源预选（`default_formats.{official,xml}`）。
  - 分册：PDF 页数、EPUB 文档数（0=不分册）；**分册模式**四选一
    `不分册 / 按刊本册 / 按目录（部类）/ 合并时选择`，后两者带**深度**（1–5，默认 2）。
    「合并时选择」＝每次点合并弹框选模式与深度（见 §7）。
- **自制E书**：**自制书籍：○校验 ○无校验**（`xml2pdf.verify_build`）——选校验后，
  右栏 `[自制]/[重制]` 生成后逐本校验、仅通过项导入；另含 自制程序路径 /
  CBETA XML 目录（传 `--cbeta-ebook`，不可为空）/ 自制电子书目录（默认 `cbeta_xml_ebooks`）/
  校验工作目录（默认 `cbeta_verify`）/ 默认预设。均带浏览按钮。
- **封面/版式**：整理者/左上角文字/PDF 合并模式（打印/阅读单选）/**说明页标题 + 自制书说明**
  （标题下一行居中，仅自制显示，默认「依 CBETA XML 自制」，其后空一行）/
  图像（佛像/韦陀）/字号/边距/字体颜色比例；「字体」子页签含**说明页简介**
  （三行丛书信息，默认仿宋、单行行距）。
  说明页部类/刊本分组信息**每段一行**（路径按 ` / ` 拆），字体沿用目录条目。
- **目录过滤**：部类/三藏、朝代、刊本（子页签，可全选/全不选）。
- **缓存**：缓存统计与清理。
- **更新源**：更新频率（daily/weekly/monthly/manual，启动时后台检查目录/元数据更新）
  + 源表（只读 URL/本地文件）+ 立即检查 + 恢复备份。
- **外观**：主题、语言（单选，暂为桩）、应用字体/字号/补充字型。
