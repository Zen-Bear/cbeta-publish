# CBETA 发布程序 — UI 设计

> 2026-09-17 合并整理：吸收旧《UI设计.md》与《链路B-UI设计.md》，去重并同步实现。
> 总方案见《设计总案.md》，跨仓调用契约见《链路B-设计契约.md》。

## 1. 整体布局

单窗三栏 + 底部页签，路径「浏览 → 勾选 → 工作区 → 右栏丛书 → 发布」：

```
┌──────────────────────────────────────────────────────────────────┐
│ 设置…   制作书籍   视图                                            │
├──────────────┬──────────────────────┬──────────────────────────────┤
│ 左栏         │ 中栏（工作区）        │ 右栏（丛书）                  │
│ 视图单选     │ 书籍列表              │ 丛书下拉 / 分类筛选           │
│ 搜索+过滤    │ 排序 全选/不选/…      │ 格式 / 来源 / 预设 / 生成     │
│ 目录树/工作区│                       │ 发布按钮 / E书目录            │
│              │                       │ 书单（拖拽排序）              │
├──────────────┴──────────────────────┴──────────────────────────────┤
│ 页签：书籍信息 | 丛书信息 | E书目录                                  │
└──────────────────────────────────────────────────────────────────┘
```

- **视图切换**：菜单「视图 → 三栏（含选书区）/ 二栏（隐藏选书区）」单选。
- 二栏时「工作区」与「目录区」二选一显示（搜索行按钮切换，带计数）。
- **分隔条**：宽 12px，条上仅一组 ◀/▶ 箭头（7pt）——相邻两栏都正常时 ◀ 收起左邻、
  ▶ 收起右邻；左邻已收起时 ▶ 恢复左邻，右邻已收起时 ◀ 恢复右邻
  （二栏时即为「左栏/右栏」）。

## 2. 左栏（导航 / 搜索 / 工作区）

- **视图**为单选按钮（部类/三藏/刊本/朝代/作者/丛书；`_RadioBar`，接口仿 QComboBox）。
  作者视图去僧姓前缀后同名归并（如源数据的 `釋窺基` 并入 `窥基`，部数相加；
  显示归并后本名，源数据文件不动；同名异人极罕见，与别名索引同策略）。
  作者搜索按作者 id 取全部挂名作品（同 id 多节点收齐，不只取首个）。
  作者条目下挂著作叶（展开浏览/双击单加/拖拽共用）。
  作者搜索按作者 id 取全部挂名作品（同 id 多节点收齐，不只取首个）。
- 二级过滤随视图显隐：部类过滤（三藏/部类）、刊本过滤、标签筛选、朝代/作者排序。
- **丛书视图**：固定为**树**（分类→丛书→书籍）——按 `categories.json` 顺序分组，空分类也显示；
  分类节点默认展开、双击仅展开折叠；**分类下拉保留作筛选**（选中某分类时树只显示该分类），
  标签筛选保留、与分类筛选叠加。
- **搜索**：经名/作者/经号，英文大小写不敏感，繁简/异体变体；覆盖所有视图。
  结果各视图统一按经号自然序（字母前缀，数字）排列（截断 `[:200]` 之前排序）。
- **目录树配色**：书叶（单本）文字黑色，分组节点沿用主题色；选中/悬停与中栏列表
  完全一致（选中 `#bbdefb`、悬停 `#fff3c4`、选中+悬停 `#90caf9`）。
- **工作区**：唯一内存书单（与中栏同一份数据，两个视图）；搜索行按钮：`✕ 清除`、
  `＋`（搜索结果加入工作区）、`工作区（N）`（与目录区切换）。
- 交互：目录树拖入工作区/右栏、双击书加入（三栏→工作区；二栏→右栏）、双击丛书/作者追加其书目、
  右键单书叶"打开本地书"（按源分组列格式，丛书树自制→缓存→本地库，其它树反之；单文件直开，多卷开首个＋目录行；同一 work 的多个自制产物逐个列出）。
  双击仍打开该 work 该格式的第一个可用产物；要打开其余分册产物请用右键逐个打开。

## 3. 中栏（工作区）

- 书籍列表（`_refresh_ws_views` 渲染，与左栏工作区同一数据）。
- 排序：原始顺序（默认）/ 经号 / 经名；全选/全不选/加入已选/全删。
- 点书 → 右下「书籍信息」页签显示；双击书 → 加入右栏并移出工作区（移动语义）。

## 4. 右栏（丛书）

- **重名规则**（跨分类按丛书名全局判重）：新建/另存为/空白保存/**改名**撞名 → 弹「重名」请换名，
  不覆盖；文件名占用（斜杠方向/大小写不同仍是同一文件，归一化比对）→ 自动
  `{name}_{i}.json` 避让。普通保存按原路径直接覆盖。
- **丛书行**：`[空白]` 在丛书下拉框左边（下拉框 stretch 收窄）；
  **管理行**：保存/另存/恢复/**改名**/删除/标签——改名在删除左，重名拦截同空白保存，
  成功立即落盘（文件名不变，只改内容）。改名/另存/删除/保存空白丛书后，左栏若为「丛书」
  视图会同步更新（改名、分类归属、移除）。

```
格式：[☑ pdf] [☑ epub] [☑ docx]      （其它格式用ZIP/导出）
来源：○ 官方  ○ 自制   预设：[ 我的配置 ▾ ] [调整…]   （预设仅来源=自制时启用）
发布：[合并] [ZIP] [导出] [下载/更新]                 （来源=自制时改为 [自制] [重制]）
```

- **格式**：pdf/epub/docx 勾选（docx 默认勾选，是 xml2pdf 主要特点）；
  **合并只取其中 pdf/epub**（仅勾 docx 点合并会提示）；docx 走 ZIP/导出/校验/打开。
  勾选职责（各框有 tooltip）＝用于「自制生成/下载/校验」与书单「已有」标志；
  其它格式走 ZIP/导出弹窗。
- **来源**：互斥，读写全局 `default_source`（`official`/`xml`），改动即落盘。
- **预设**：紧接「自制」单选右侧；xml2pdf 仓库（[cbeta-xml2pdf](https://github.com/Zen-Bear/cbeta-xml2pdf)）`presets/` 下 stem ＋「出厂默认」；改动写回全局。
  `[调整…]` 打开上游 `XmlOptionsDialog`：点「确定」＝写成**临时预设**、
  本次立即生效并强制重生成；随后问「保存为预设？（覆盖/另存为/不保存）」，
  选不保存即改选预设/退出时丢弃。临时生效时预设行显示「预设(本次):」。
- **生成策略**：**合并/ZIP/导出按「缺/过期」备齐**（已有且不过期直接复用、只补缺/过期）：
  自制书若源 XML 较新（工作根 `{work} {书名}/*.xml` 最新 mtime 晚于任一产物）则自动重制；
  官方书过期 = 缺失 ∨ 源 XML 较「备齐水位」新 ∨ 本地库版本名（`official_library.root` 目录名）变化
  （水位记 `config/official_state.json`，gitignored）；需整体重生成先点 `[重制]`。
- **缺书/更新确认**（官方源；合并/ZIP/导出一致）：列出「未下载/需更新」；是=先下载/更新
  （**下完仍缺再问「是否继续（仅打已有）」**，选是=继续，选否=取消），**否=跳过继续**（只打已有，
  缺的记失败），取消=不打。
- **发布行**：来源=官方显示 `[下载/更新]`；来源=自制显示 `[自制]`（补缺）、
  `[重制]`（全部重生成）。**设置「制作书籍」=校验时，这两个按钮生成后逐本校验、
  仅通过项导入**（见 §8）；=无校验时只生成。
- **书单**：
  - 格式图标：**双击打开**该格式（不存在无反应）；tooltip：存在=「双击打开」、
    缺=「XX未下载」。**双击书名**：打开存在的格式（先 PDF，再 EPUB，再 DOCX）。
  - 行内复选框为右栏本地标记（供移除收集），与中栏勾选独立。
  - 拖拽排序（分层按「书单分组」视图，见下）；拖出到左栏 = 移除（进工作区）。
    拖放后自动展开目标卷并定位/选中被拖的书（不再“拖完不见”）。
- **书单分组**（显示方式下拉在书单下方按钮行、**「移除」左边**；
  其**左边**另有 `分册…` 按钮＝编辑当前丛书分册配置，见 §7；内存记忆、不落盘）：
  `平铺`（默认）/`按刊本册`/`按部类`（后两者为**只读视图**，从目录/刊本即时分组，禁拖拽与上下移）
  /`手工分册`（可编辑两级树：**第N册〔· 副标题〕 → 书名**；未分组的书归底部「未分组」）。
  手工分册右键菜单：书行「新建分册（含选中书）/ 移入分册 ▸（含未分组）」，
  卷头「设副标题…/ 上移 / 下移 / 删除分册 / 新建空分册」；卷按顺序自动编号（增删/移动后重排）。
  只读视图（按刊本册/按部类）右键另有**「拷贝全部分册覆盖到手工分册」**，
  在卷头上则为**「拷贝此分册覆盖到手工分册」**——把当前自动分册结果固化进手工分册（覆盖）并切到手工视图。
  拖拽：书落卷头=入卷，落书=按落点插到同卷；落空白=移到未分组。
  数据存丛书 JSON `manual_volumes:[{title, work_ids}]`（顺序=册序；`work_ids` 仍是全书单真相，
  卷内顺序不独立存放，改动即时标星号，随「保存」落盘）。
- **按部类归属（同书多部类）**：CBETA 部类树里同一本书可能属于多个部類（如 16 淨土部類的书
  同时在 06 寶積部類/10 密教部類）。从**部类树**拖入的书会记录来源部类路径（`bulei_groups`，
  全路径；「按部类」分组/合并时按当前深度截断后优先用它），于是从 16 拖入的仍归 16，不再被
  06/10 首个命中抢走。刊本/作者/丛书/搜索/工作区拖入无部类上下文，按自动解析（`bulei.txt`
  首次命中，即旧行为）；存量书亦保持旧行为，从部类树重拖即可修正。
- `source`/`work_sources`/`xml_options` 只读兼容，不再写入、不参与决策。

## 5. 右下页签

- **书籍信息**：点书显示（经号/经名/作者/卷/文件）。下载/自制完成后列出本次产物；
  **校验（自制/重制=校验、导入校验通过E书）后列出逐本/逐格式结果**——
  已入库、未入库（含"未入 epub"这类部分通过信息，警示色）、未判定，附
  验证输出目录/已入库目录链接（可点开），显示自动回到第一行。
- **丛书信息**：丛书名/分类/部数/最后发布/标签/产物链接（可点击）；合并/ZIP/导出
  成功后切到本页签。
- **E书目录**：`官方`/`自制`/`丛书` 三个可点链接（点击打开对应目录，悬停看全路径，
  右侧显示完整路径；设置变更后刷新）。

## 6. 菜单

- 「设置…」（菜单栏直达，`Ctrl+,`）。
- 「制作书籍」：
  - `批量处理…`（**不新开一级菜单**；一个窗口内用顶部单选切「更新素材 / 合并丛书」（默认更新素材）；
    「来源」单选（官方书/自制书，默认官方，只显示对应策略；更新模式＋自制时另有 XML 归属灰字提示）；
    「选择丛书」行右对齐「全选/全不选」；合并模式点击列表**「分册」列**任一一行即进入该丛书分册设置；
    设计见 `docs/批量合并-设计与实施.md`）：
    - 更新素材：只对所选丛书备齐（官方缺/过期重下 + 自制源新重制），不合并、不写 `last_publish`；
      报告 `output_dir/批量更新报告.txt`。
    - 合并丛书：☑合并 ☑ZIP（格式沿用 `default_formats`）☑合并前自动备齐（默认开）
      ☑清除上次合并输出（默认关，删 `output_dir/{名}/`＋清发布标记，执行前二次确认）☑报告落盘；
      官方刷新策略（默认「XML较新则重下」）、自制策略（默认仅缺/自动源新重制）；
      输出 `output_dir/{丛书名}/`、报告 `output_dir/批量合并报告.txt`；
      可设单书分册配置（**重用合并分册窗口**＋「跟随全局」，确定即落盘到该丛书 JSON；
    清单「分册」列显示来源：`丛书：…`/`跟随全局：…`）。
  - `运行 xml2pdf 制作书籍…`：打开独立窗，并把**当前丛书**书单（`{slug}_ids.txt`）、
    输出目录（同丛书校验目录，便于后续导入）、预设、格式带过去；窗内可再编辑，不自动开跑。
    打开前检查预设的 `source.cbeta_ebook`（工作根）是否与 publish 一致，
    不一致则提示并可一键对齐（覆盖保存该预设）。
  - `导入校验通过E书…`：手动导入——**每次都弹目录选择**（默认指向当前丛书托管校验目录
    `verify_dir/<丛书>/`，可改选独立窗输出目录，其中含 `*_verify_report.txt`、
    `*_校验报告.txt` 或 `（验证）/report.txt` 即可），不再默认直接导入上一次的书籍。
     结果写入「书籍信息」页签：首行总验证报告链接（`verify_dir/<丛书>/总验证报告.txt`，
     自制/重制跑完与手动导入均写），已入库条目列出每部书入库了哪个格式文件（可点开），
     未判定条目标注原因（如无基线），失败条目带缺数/多余数（如 `epub 缺48/多97`）。
    有未通过/未判定项时询问是否人工检验：看报告后可勾选放行入库（结果页标"人工放行"）；
    托管校验目录内未放行的暂存产物删除，外部目录不删。
  - `导入说明…`：只读弹窗，内容同《链路B-设计契约.md》§9。
  - 右栏「调整…」：面板内预设下拉默认选中 Publish 当前预设。
- 「视图」：三栏/二栏单选。

> 「校验重制」已从菜单移到**右栏发布行**按钮（来源=自制时显示）。

## 7. 合并 / ZIP / 导出 / 校验（交互变化点）

1. 点「合并」→ 空书/空白改名检查（来源、预设取右栏；自制生成恒「仅缺」）；
   分册按设置 `merge.mode`：
   - `不分册/按刊本册/按目录/按手工分册/按作者/按朝代` → 直接按该模式合并
     （按手工分册＝按右栏「手工分册」卷分组，卷序=册序，未分组自成一组；
     无手工卷时回退不分册；按作者/按朝代＝按作者（译/撰者）/朝代分组，
     未署名/未詳置末，朝代为单一维度、忽略深度）；
   - `合并时选择` → **弹「合并设置（分册）」**：模式六选一 + 深度 1–5（默认 2）
      ＋文件名模板输入（深度右侧，确定后同步设置 `merge.name_template` 并落盘）
      ＋预览（首组原文全文示例，随深度动态变化；清单只列文件名、无后缀；
      不分册无例子行、清单显示单文件名，随模板实时展开），
      选择记忆（`merge.ask_last`）供下次默认；取消则中止（模板改动不写回）。
  - 命名：分册文件名模板（`merge.name_template`，设置页可改；缺省 `{coll}.{nn}.{seg}`；
    不分册同样走模板，此时无序号（`{n}`/`{nn}` 置空，缺省即丛书名本身），
    `{coll}`/`{count}` 可用）：
    占位 `{coll}` 丛书名、`{n}` 全局序号（不补零）、`{nn}` 全局序号（自适应补零，
    宽度＝总文件数的十进制位数，拿不到总数时固定两位）、`{seg}` 末段名、
    `{seg0}` 首段前导数字（如 `06 寶積部類` → `06`，无则空）、
     `{seg1}`…`{segN}` 第 N 段（超出段数为空；`{seg1}` 去掉首段前导数字）、`{count}` 本组部数（合并弹框
    每行显示的部数，可直接用于文件名，如 `.{count}册`）、
      `{source}`（同 `{src}`）本次来源（官方/自制）、`{date}` 今天（YYYY-MM-DD）、
      `{date8}` 今天（YYYYMMDD）、
      `{stem}` 下划线全路径、`{label}` 斜杠全路径、`{count}` 本组电子书部数（裸数字）。
      缺省＝路径段清洗后用 `_` 连接（如 `太虛大師全書_法藏.pdf`、
      `01 阿含部類_長阿含經.pdf`）；例 `{coll} {seg}` → `太虛大師全書 01 編纂說明.pdf`，
      `{coll} {nn} {seg}.{count}册` → `太虛大師全書 02 法藏.12册.pdf`。
      段内**全角 `／` 保留**（如 `中觀部／疏`），
      经号（`T30a`/`T1564-67`/`K41`/`X46,54`…，续号字母后缀如 `T11-12a,26a,37,40b` 一并去掉，
      否则残留孤立 `a`/`b`）与 `etc.` 去掉，
      作者等正文保留（如 `二諦義 (3卷)【隋 吉藏撰】`）；未命中 → `未分册` / `未歸類`（置末）。
      不分册输出名保持 `{丛书名}` 不变；合并弹框预览文件名与实际落盘同规则。
2. 点「ZIP」/「导出」→ 弹「选择打包格式」（官方 7 种、自制 3 种；预选＝设置里对应来源的默认格式）。
   目录型只打包不合并：ZIP 按 `部/相对路径` 写入 `{丛书名}_{fmt}.zip`，
   导出整树拷贝到 `{target}/{work}/`。
   包内/导出文件名用显示名（与合并书名书签同款 `title_of`，如 `T0001 長阿含經.pdf`；
   取不到书名回退裸 id；包内重名自动 `_{n}`；目录型只改顶层段，内部相对路径不变；
   缓存键不动）。
   **按分册（同合并）**：读全局 `merge.mode`；`不分册` 保持现状（单 zip／平铺导出）；
   其它模式按**可用书**分册——ZIP 每组每格式一个 `{基名}_{fmt}.zip`、
   导出每组每格式一个目录 `{target}/{基名}_{fmt}/`（基名＝合并模板 `merge.name_template`，
   同合并命名）；「合并时选择」复用同一弹框（含模板/预览，共享 `merge.ask_last`）；
   组重名自动 `_2` 去重；空组/缺书跳过并计入结果。
3. 来源=官方且缺书 → 弹「是否先下载？」（按格式分别显示缺数，如 `pdf 缺 5 部、epub 缺 3 部`，不列文件名）；来源=自制缺则生成（已有复用，不自动重生成）。
4. 进度窗（`_make_progress`，复用）：可滚动日志+进度条+取消；前置下载无错时 3 秒自动关闭续跑。
5. **自制/重制（设置=校验时）**：进度窗逐本「生成并校验 X …通过/部分通过/未通过」，
   跑完**逐格式**自动导入（通过项入库，未通过格式不拖累，如 docx 过、epub 没过则只入 docx）；
   总结「校验完成 x/y／验证输出目录：<可点目录>；已自动导入 n 部；未通过/未入库（警示色）」
   （见《链路B-设计契约.md》§5）。

  字体子页签可另设编辑说明标题/正文字体）；
  打印模式保证说明页从奇数页起（编辑说明后按需垫空白；多页前置按真实页数算，
  不多垫不少垫）；编辑说明/说明/目录/正文书签与目录内链均指真实内容页。
  视觉演示（全开时所有页 + 逐页设置标注 + 封面元素编号图例 + 元素对照表）见
  [`docs/封面布局演示/README.md`](封面布局演示/README.md) 与生成的
  `docs/封面布局演示/封面布局演示.pdf`（`gen_cover_demo.py` 重新生成）。

- **缓存**：缓存统计与清理。
