## 3. 核心模型

- **三套目录统一**：部类 `bulei.txt`、藏册 `SutraList.json`、在线 `catalog`，以 `work`（`T0001/X0367`）关联，范围 `T1745..T1748`。

## 4. 架构（Python+PySide6，无转化）

```
publish/
  mulu/                 # 官方只读，远端覆盖
    bulei.txt, SutraList.json, sutra_mapping.txt, all-creators..., file-structure.md
    cache/meta.json
    backup/original|last    # 仅2份
  collections/          # 用户丛书，与 mulu 并列
    index.json, tags.json, categories.json
    author/ sect/ sutra/ theme/ custom/
  cbeta_xml/                 # XML 缓存
  cbeta_publish/
    catalog/bulei_parser.py, sutra_service.py, mapping_service.py
    creators/creator_service.py
    books/source.py, cache_manager.py, remote_manager.py
    collections/collection_model.py, tags_manager.py, category_manager.py
    gui/main_window.py, theme/, i18n/
  config/app.json       # theme/language/book_dir（不走 mulu，避免被覆盖）
```

数据流：`mulu/` → 树/搜索 → 勾选 → `collections/<category>/<slug>.json` → `cbeta_xml/` 下载 → 导出 `selection.json` → 外调转化。

## 6. 丛书合成双链路（2026-08-28 新增，2026-08-28 修订：用户指定源）

| 链路 | 输入 | 工具 | 输出 | 用户指定 |
|------|------|------|------|----------|
| **A 官方电子书→丛书** | 官方已发布 `pdf/epub/mobi`（如 `T0001.pdf`） | `books/official_ebook_source.py` 下载到 `cbeta_ebooks/{format}/` | `cbeta_ebooks/pdf/{work}.pdf` 等 | 用户在丛书创建时 **指定格式** `[pdf●][epub○][mobi○]` 多选，下载所选格式，合成时按所选格式合并 |
| **B XML→电子书→丛书** | `cbeta_xml/XML/...xml` | `E:\dev\cbeta\xml2pdf:1`（`pycbeta`） | `output/ecbeta_xml/{work}.pdf` | 用户指定链路，批量调 `xml2pdf` 生成所选格式后合成 |

- **不自动选源**：UI 丛书 `来源` 单选 `○ 官方成品 ○ XML现制`（或每本书单独指定），`[合成]` 按指定源执行。
- **格式选择**：官方源需选择 `pdf/epub` 等（多选），`cbeta_ebooks/` 按格式分子目录。

### 电子书合并技术设计（单一格式，允许分册，2026-08-28 修订）

> **不做混排**：丛书内强制单一格式（`pdf` 或 `epub`），跨格式需用户分丛书；**允许分册**（如 `太虚全集 上/中/下`）；此模块可独立为子项目 `ebook_merger`。

| 场景 | 工具 | 关键实现 | 分册 |
|------|------|----------|------|
| **PDF+PDF** | `PyMuPDF(fitz)` | `merger.insert_pdf` + `set_toc`（每 `work` 一级书签）+ 封面页 | 丛书 `work_ids` 按阈值（如 5000页 或 500MB）自动切 `part1.pdf/part2.pdf`，`index.json` 记 `parts:[{file, works}]` |
| **EPUB+EPUB** | `ebooklib` | 合并 `manifest/spine` 去重 `id`，重排 `nav.xhtml`，`write_epub` | 同上，按 `spine` 长度切册 |
| **XML→电子书** | `E:\dev\cbeta\xml2pdf:1` | **置后**：需交互 UI `纸张大小/边距/字体/输出格式` 等，暂不做；先聚焦 **官方丛书合集**，`xml2pdf` 链路预留接口 `cbeta_publish/books/xml2pdf_bridge.py` |

UI（官方合集优先）：丛书 `来源: 官方`，`格式: [pdf●][epub○]` 单选，`[下载选中格式]` → `[合成]`（同格式）→ 选 `是否分册 [阈值:5000页]` → `output/<丛书>/`。

> `xml2pdf` 交互（纸张 `A4/B5`、边距、字体等）置后，接口已预留。

## 7. 丛书与分类（核心）

### 存储与并列

```
collections/
  index.json            # [{id, name, category, tags, work_count, updated_at, last_publish_at, path}]
  categories.json       # 顶层种类，可增改
  tags.json             # 标签树 {tags:[{id, name, parent, level}]}
  author/太虚大师全集.json
  sect/华严宗文集.json
  sutra/金刚经注解集.json
  theme/禅修文集.json
  custom/我的随选.json
```

`mulu/` 官方只读，`collections/` 用户可写，并列分离。

### 分类（顶层种类，可增改，悬停显示描述）

- 预设 `collections/categories.json:1`（已按你要求 `主题→专题`、`自选→其他` 细化，`2026-08-28`）：
  ```json
  {"categories":[
    {"id":"author","name":"作者","description":"按作译者汇集，如太虚大师全集"},
    {"id":"sect","name":"宗派","description":"按宗派传承，如华严宗、天台宗文集"},
    {"id":"sutra","name":"经论","description":"按单经/论及其相关注解汇集"},
    {"id":"theme","name":"专题","description":"按修学专题，如禅修、戒律、净土，需配具体标签"},
    {"id":"custom","name":"其他","description":"未分类或个人随选，兜底分组"}
  ]}
  ```
- **可新增/改名**：UI “分类管理”增删改 `categories.json`，改名批量更新所有丛书 `category`，新增即新建 `collections/<id>/`；鼠标悬停显示 `description`。

### 标签层级（可多标签，层级不难）

- `collections/tags.json:1` 存树 `[{id:"theme:chanxiu", name:"禅修", parent:"theme", level:1, description:"禅修方法、止观相关"}, ...]`，`parent` 关联 `categories.id` 或父标签，支持 `禅修/初阶` 二级。
- 一丛书 **可多标签** `tags: ["author:太虚","theme:禅修"]`，筛选 AND/OR。
- 新增/改名/删除：改 `tags.json` 并批量更新所有丛书 `tags[]`，悬停显示 `description`。

### 模型（仅留最后 publish）

```json
{
  "id": "author_taixu_20260828",
  "slug": "author_taixu_20260828",
  "name": "太虚大师全集",
  "category": "author",
  "tags": ["author:太虚","theme:民国"],
  "work_ids": ["B0123"],
  "works": [{"id":"B0123","title":"真现实论","file":"B03n0123_001.xml"}],
  "created_at": "2026-08-28T10:00:00Z",
  "updated_at": "2026-08-28T10:20:00Z",
  "last_publish_at": "2026-08-28T10:20:00Z",
  "last_publish_dir": "output/太虚大师全集"
}
```

- 创建：搜索+勾选→命名，`category` 必选决定子目录，`tags` 可选。
- 仅保留 `last_publish_at` + `last_publish_dir`，发布覆盖。

### id 选型（按你要求：可读 slug）

- **采用 `可读 slug`**：`{category}_{pinyin}_{YYYYMMDD}` 如 `author_taixu_20260828`，`sect_huayan_20260828`，`sutra_jingang_20260828`。
- 生成：`pinyin(name)` + 时间，冲突加 `-1`。**不可变**：重命名 `name` 不改 `id/slug`，文件名为 `slug.json` 或 `name.json` 二选一（建议文件名用 `slug.json` 避免中文路径问题，`name` 存 JSON 内）。
- 对比 UUID：slug 可读、排序友好，满足你偏好；缺点拼音歧义但可接受。

`mulu/backup/original/`（出厂重置点）+ `mulu/backup/last/`（覆盖前快照），各 5 文件，`[重置到原始]`/`[恢复上一次]` 两按钮。
