# CBETA 大藏经发布程序 — 设计总案

> 2026-09-17 合并整理：吸收旧《设计总案.md》《UI设计.md》与《链路B-UI设计.md》
> 的总览部分，作为唯一「总方案」；UI 细节见《UI设计.md》，跨仓调用契约见
> 《链路B-设计契约.md》，待办见根目录 `TODO.md`。
>
> 形态：Python + PySide6，单窗三栏；**转化逻辑全部外置于 xml2pdf 仓库
> [cbeta-xml2pdf](https://github.com/Zen-Bear/cbeta-xml2pdf)**（本机路径 `E:/dev/cbeta/xml2pdf`），
> 本程序只做目录/搜索/选书/下载/生成调度/合并/打包。

## 1. 目标与范围

**做**
- 目录显示：部类 / 三藏 / 刊本 / 朝代 / 作者 / 丛书 六视图（本地 `mulu/` 派生）。
- 搜索与勾选：关键词/经号/作者 → 工作区（唯一内存书单）→ 右栏丛书。
- 双缓存管理：官方成品电子书 `cbeta_ebooks/`、自制电子书 `cbeta_xml_ebooks/`。
- 丛书管理：分类/标签/排序/保存/恢复/另存/删除；发布元数据（最后发布时间与目录）。
- 成书两条链路（见 §3）：合并 / ZIP / 导出 / 校验重制。
- 目录数据与元数据的远端增量更新（ETag/大小兜底）。

**不做**
- 转化（XML→电子书）逻辑：全在 `xml2pdf`，本程序只调度。
- 逐书来源细粒度（`work_sources` 只读兼容，来源按整套丛书/全局选）。
- 自制书以源 XML 最新 mtime（工作根 `{work} {书名}/*.xml`）判断是否过期：源较新则「仅缺」也重制；
  官方书不做 mtime/哈希推断（合并/ZIP/导出恒「仅缺」；整体重生成用「重制」）。
- 深色主题 / 完整 i18n（不做）。

## 2. 架构与包结构

```
publish/
  mulu/                      # 官方只读元数据（可远端更新）
  collections/               # 用户丛书（与 mulu 并列）
    index.json  categories.json  tags.json
    author|sect|sutra|theme|custom/<slug>.json
  config/app.json            # 运行配置（来源/目录/封面/分册…）
  cbeta_ebooks/              # 官方成品电子书缓存
  cbeta_xml_ebooks/          # 自制电子书输出（= 配置键 xml_to_ebooks_dir）
  cbeta_verify/              # 校验重制的工作区（= verify_dir）
  collections_books/         # 合并/ZIP/导出 的丛书产物根（= output_dir）
  cbeta_publish/
    app.py                   # 入口（python -m cbeta_publish.app）
    paths.py                 # app_root()：数据根（冻结=exe 同级目录，源码=仓库根）
    catalog/                 # bulei_parser, bulei_index, sutra_service, mapping_service,
                             # tripitaka_service, dynasty_service, vol_service, work_id
    creators/creator_service.py
    collection/              # collection_model, category_manager, tags_manager
    books/                   # official_ebook_source, xml2pdf_bridge, ebook_merger,
                             # download_worker, verify_worker, update_worker,
                             # remote_manager, remote_sources, cache_manager
    gui/                     # main_window, settings_dialog, merge_dialog, theme/icons
    i18n/i18n.py
    _vendor/cbeta_fetch.py   # 官方共享下载层（勿改；见 mulu/REMOTE_SOURCES.md）
  packaging/                 # PyInstaller spec + 打包说明
  build_exe.ps1              # 一键打包（onedir，产物名取 APP_ID）
  demo/                      # 示例产物（自制 docx/pdf、合并 epub），仅仓库展示
  LICENSE                    # GPL-3.0（Copyright (C) 2026 Zen Bear）
  tests/                     # unittest，`python -m unittest discover tests`
```

数据流：`mulu/`（树/搜索）→ 工作区 → `collections/<cat>/<slug>.json`
→ 官方下载 `cbeta_ebooks/` 或自制生成 `cbeta_xml_ebooks/`
→ `ebook_merger` 合并 / ZIP / 导出到 `output_dir/`。

## 3. 双链路

| 链路 | 输入 | 工具 | 产物目录 | 说明 |
|------|------|------|----------|------|
| **A 官方电子书** | 官方已发布成品 | `books/official_ebook_source.py`（走 `_vendor/cbeta_fetch`） | `cbeta_ebooks/{fmt}/…` | 7 种：pdf/epub 单文件；html/docx/odt/txt/txt_notes 目录型（zip 解压） |
| **B XML→自制** | work id（XML 源由 `xml2pdf` 解析） | `books/xml2pdf_bridge.py`（进程内库调用 `pycbeta.cli.main`） | `cbeta_xml_ebooks/{fmt}/…` | 预设制；pdf/epub/docx；可选「校验重制」 |

- 一套丛书**不绑定**来源；右栏按次选官方/自制，整批统一（见《UI设计.md》§4）。
- 调用方式、预设、`--config`/`--cbeta-ebook`/CSS 槽、校验流程等**跨仓契约**见
  《链路B-设计契约.md》（与 xml2pdf 会话共用）。
- 两缓存根**同构** `{root}/{fmt}/…`，根分开防复用串源。

## 4. 数据与缓存

**官方只读 `mulu/`**：`bulei.txt`（部类树，23 部類）、`SutraList.json`（藏册扁平目录）、
`sutra_mapping.txt`（`work→file` 权威映射）、`all-creators-with-alias.json`、
`creators-by-strokes-with-works.json`、`vol.json`（依刊本 26 刊本/169 册/5939 部）、
`file-structure.md`/`格式说明.txt`（目录/经号规则）。
远端源与增量见 `mulu/REMOTE_SOURCES.md`、`mulu/cache/meta.json`（ETag + 大小兜底）。

**用户可写 `collections/`**：与 `mulu/` 并列分离；`index.json` 为派生索引（可安全删除，
扫描分类目录仍是权威）。模型与 id/分类/标签规则见 §5。

**输出目录**（绝对或相对路径，显示与落盘用本地分隔符）
- 官方：`cbeta_ebooks/{fmt}/{work}.{fmt}`；目录型 `cbeta_ebooks/{fmt}/{work}/`。
- 自制：`xml_to_ebooks_dir/{fmt}/{work}.{fmt}`（同 `{fmt}/` 下 `{work}*.{fmt}` 视为已生成）。
- 校验：`verify_dir/<丛书>/`（产物 `{id 书名}.{fmt}` + `{id 书名}（验证）/` 报告）。
- 丛书产物：`output_dir/<丛书名>/`（合并/ZIP/导出）。
- 旧版平展布局（`{root}/{work}.{fmt}`）已作废：不迁移/不双读/不自动删，需手动清理后重下/重生成。
- 配置里目录可为**相对路径**（按 `app_root()` 解析：源码=仓库根，打包=exe 同级目录）；
  打包脚本会把 dev 绝对路径改写为便携相对路径（见 `packaging/README.md`）。

配置键与完整清单见《链路B-设计契约.md》§4。

## 5. 目录 / 搜索 / 丛书模型

- **三套目录统一以 `work`（如 `T0001/X0367`）关联**：部类树 `bulei.txt`、藏册
  `SutraList.json`、在线 `catalog`；归属由 `catalog/work_id.py` 规范化。
- **六视图**：部类（`bulei`）/ 三藏（`tripitaka_service`，经/律/论/藏外）/
  刊本（`vol_service`）/ 朝代（`dynasty_service`）/ 作者（`creator_service`）/ 丛书。
- **搜索**：经名/作者/经号，繁简/异体变体，覆盖所有视图（`_search_current_tree`）。
- **丛书**：`collections/<category>/<slug>.json`；`slug = {category}_{pinyin}_{YYYYMMDD}`
  （可读、不可变；重命名不改 id）。左栏「丛书」视图为树（分类→丛书→书籍）。
- **分类**：`collections/categories.json`（作者/宗派/经论/专题/其他，可增改，带 description 悬停）。
- **标签**：`collections/tags.json`（树，支持二级，一丛书多标签；改标签批量更新丛书）。
- **发布元数据**：仅 `last_publish_at` + `last_publish_dir`（发布覆盖）。

模型示例：

```json
{
  "id": "author_taixu_20260828",
  "name": "太虚大师全集",
  "category": "author",
  "tags": ["author:太虚", "theme:民国"],
  "work_ids": ["B0123"],
  "manual_volumes": [{"title": "法藏", "work_ids": ["B0123"]}],
  "bulei_groups": {"B0123": ["16 淨土部類", "B0123 淨土經"]},
  "created_at": "2026-08-28T10:00:00Z",
  "updated_at": "2026-08-28T10:20:00Z",
  "last_publish_at": "2026-08-28T10:20:00Z",
  "last_publish_dir": "collections_books\\太虚大师全集"
}
```

- `manual_volumes`：右栏「手工分册」的卷（顺序=册序）；`bulei_groups`：从部类树拖入时
  记录的来源部类全路径（同书多部类时优先用它，见《UI设计.md》§4）。二者均可选。

## 6. 合成（`books/ebook_merger.py`）

- **单一格式、允许分册**：丛书内强制同一格式（PDF 或 EPUB），跨格式需分丛书。
- **分册模式**（`merge.mode`）：`不分册` / `按刊本册` / `按目录（部类）` / `按手工分册（右栏）` /
  `按作者` / `按朝代` / `合并时选择`（弹框选模式+深度，记忆 `merge.ask_last`）。
  `merge.depth`（默认 2）＝路径取前 N 段：刊本 1=刊本名、2=刊本名_册；部类 1=顶层部类、
  2=部类_子组（仅刊本/部类有意，作者/朝代为单一维度、忽略深度）。文件名＝清洗后路径段
  `_` 连接（`catalog/catalog_path.py`；段内全角 `／` 保留，经号与 `etc.` 去掉）；
  未命中 `未分册`/`未歸類` 置末；作者/朝代分别以 `未署名`（拼音序）/`未詳`（朝代序）置末，
  朝代名去「CE 年代」区间（如 `後秦 384 CE ~ 417 CE` → `後秦`）。
- **PDF**：PyMuPDF `insert_pdf` + `set_toc`（每部一级书签，页顶锚 `BOOKMARK_TOP_MARGIN=1`）
  + 封面页 + 说明页 + 目录页（目录条目经书加序号，全局连续、自适应补零，与 EPUB 同规则）；
  `split_pages` 分册。
- **EPUB**：ebooklib 合并 `manifest/spine`，重排 `nav`，保留每部原封面/样式
  （按书内相对路径 `add_link` 重挂 CSS），排除每部自带 toc/front/back；
  目录（nav/NCX）只给经书条目加序号（全局连续、自适应补零，封面/丛书目录/
  编辑说明/说明不加）；`split_items` 分册。
- **封面/版式**：`cover.*`（organizer/imprint/mode/intro/images/sizes/styles/positions）；
  打印模式补空白页，阅读模式去空白；封面文本为流式内联样式（弱 CSS 阅读器友好）。
  丛书名形如 `丛书｜部类 / 刊本 / 子目` 时，分组路径**每段一行**（封面用目录条目字体字号）。
- **说明页**：部类统计 + 完整清单。简介三行默认**仿宋、单行行距**（`styles.intro_summary`，
  可改）；部类/刊本分组信息按 ` / ` **每段一行**、字体沿用目录条目。来源=自制时在「说明」
  标题下一行居中注 `intro["note"]`（设置「自制书说明」，默认「依 CBETA XML 自制」；官方不加），
  其后空一行。
- **ZIP / 导出**：按来源取目录；ZIP/导出时弹格式选择（官方 7 种、自制 2 种），
  目录型只打包不合并（`部/相对路径` 写入 zip / 整树拷贝）。官方缺书：是=先下载
  （下完仍缺再问是否继续）、否=跳过缺书继续、取消=不打（合并/ZIP/导出一致）。
- **校验重制**：进程内逐本生成+校验，跑完自动导入通过项（见《链路B-设计契约.md》§5）。

## 7. 更新与缓存管理

- `RemoteManager`：`cbeta_fetch.probe_info` + ETag（去 `-gzip` 后缀）+ 远端大小兜底；
  条件头 HEAD 未变即跳过。
- `cache_manager`：目录大小统计与清理（设置页「系统/缓存」页签）。
- `update_worker` + `update_interval`：后台检查目录/元数据更新。

## 9. 打包与分发

- `build_exe.ps1`（PyInstaller onedir）：产物 `dist/<APP_ID>/`（含 `cbeta-publish.exe`）；
  可写数据（`config/ mulu/ assets/ xml2pdf/ collections/`）放 **exe 同级**，便携；
  默认同时生成 `dist/<APP_ID>.zip` 交付包；`-WithBrowsers` 可连 Chromium；
  `-CertThumbprint`/`-PfxPath` 可做代码签名。细节见 `packaging/README.md`。
- 打包会包含演示丛书 `collections/`；`demo/` 仅仓库展示，不入包。
- 应用名/短名/版本单一来源：`cbeta_publish/__init__.py`（`APP_NAME`/`APP_ID`/`__version__`）。

## 10. 术语

- **官方**：CBETA 官方发布的成品电子书（下载到 `cbeta_ebooks/`）。
- **自制**：由 `xml2pdf` 根据官方 XML 制作的电子书（输出到 `cbeta_xml_ebooks/`）。
- **work id**：CBETA 经号（`T0001`、`X0367`、`TXa001`…），规范化规则见 `catalog/work_id.py`。
