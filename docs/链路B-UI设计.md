# 链路 B UI 设计（已实施）

> 状态：已按此实施（库调用＋右栏来源/预设＋平展目录＋说明页注明）。
> 相对 v2 的修正（用户意见）：来源**不进合并弹框**，改在**右栏**放
> 官方/自制选择按钮；选中自制后出现预设下拉，默认取全局配置。
> 约定：配置键用 `xml_to_ebooks_dir`（自制书输出根，默认 `cbeta_ebooks_xml`）。

## 0. 术语

- **官方**：从 CBETA 官方下载的成品电子书（`cbeta_ebooks/`）。
- **自制**：由程序根据官方 XML 制作的电子书（`xml_to_ebooks_dir/`），不管 XML 来自本地还是下载。
- 一套丛书**不绑定**来源；右栏选本次来源（官方/自制），整批书统一用该来源。

## 1. 右栏（丛书区）：来源单选＋预设下拉

位置：右栏「发布」分组框内，格式复选框上方，加两行：

```
来源：○ 官方  ○ 自制
预设：[ 我的配置            ▾ ] [调整…]     （仅来源=自制时启用）
```

- 来源 radio 互斥，读/写全局 `default_source`（存值 `official`/`xml`，
  显示中文；改动即写回配置并落盘，下次默认上次的选择）。
- 预设下拉内容＝xml2pdf 仓库 `presets/` 下预设名（stem）＋首项"出厂默认"（空值）；
  默认选中全局 `config.xml2pdf.preset`；改动同样写回全局。
- `[调整…]`：打开上游 `XmlOptionsDialog`（预填当前选中的预设）→ 确定后取
  `dlg.get_preset(base)`，再选「覆盖」当前预设或「另存为…」新预设名 →
  经上游 `save_config_preset` 写入 `presets/<名>.json` → 下拉刷新并选中；
  取消则什么都不改。
- 来源=官方时预设行整行置灰（含 tooltip 说明原因）。
- 预设名不存在（被删/改名）时：下拉回退到"出厂默认"并红字提示。
- 丛书 JSON 的 `source` / `work_sources` / `xml_options` 只读兼容，
  不再写入、不参与合并决策。

## 2. 设置页（数据/输出页）

- 目录行（目录数据/丛书数据/官方电子书/输出目录）
  都有「浏览…」按钮，打开目录为当前值所在目录（空则工程根）。
- **「自制」组框**，内含5行：默认来源 / 自制程序路径 /
  XML 工作根 / 自制电子书目录 / 默认预设。
  - 默认来源下拉显示中文：`官方` / `自制`（存值仍为 `official` / `xml`）。
  - 自制程序路径（原"xml2pdf 路径"改名）、XML 工作根（`xml2pdf.cbeta_ebook`，
    传 `--cbeta-ebook`；留空=由对面自身配置决定）、自制电子书目录均带浏览按钮。
  - 预设目录固定在自制程序仓库 `presets/`（对面 `user_presets_dir`），
    publish 不另配；默认预设下拉列出该目录下预设名（stem）＋"出厂默认"。
  - tooltip："默认预设：自制电子书由程序根据官方 XML 制作；合并时来源选"
    "自制且未另选预设时使用此项"。
- 删除旧4行（纸张/字库/引擎/竖排）；旧值照读兼容但停传。
- XML 源配置已删除（XML 缓存 book_dir / 本地 CBReader local_xml_root）：
  XML 源解析归 xml2pdf（`materialize_work`），publish 不再配置；
  CBReader 书库是 P5a（按卷切分），不是对面要的 P5（整部经），
  之前拿它定位只会喂错文件。
- 所有目录统一绝对路径：缺省值即绝对；相对值按工程根解析（`bridge._abs`）；
  设置显示与落盘都用本地分隔符（Windows 反斜杠）。

## 3. 合并流程（无新增弹框）

点「合并」→ 空书/空白改名检查（不变）→ 缺书下载（不变）→ 合成；
来源与预设取右栏当前选择（§1），不再另弹框。
（后续"按目录分册"的模式/维度/深度选项届时再议放在哪。）

## 4. 生成进度窗（复用下载窗组件）

- 与「下载/更新」弹窗**同一个** `_make_progress`（可滚动日志＋进度条＋取消），标题为 `XML 生成（N 部）`。
- 日志逐本一行：`生成 T0001.pdf …完成 312KB` ／ `…失败（原因）`（失败红色）；进度条按本推进。
- 「取消」：本次完成后停（不再开下一本），已生成的保留，汇总行写"已取消"。
- 成功结束：窗口保留，显示"完成 x/y"，用户点「关闭」（**不**自动关闭）。

## 5. 说明页来源注明（整页一句，非逐本标签）

- 本次合并来源是**自制**时，说明页 summary 追加一句：
  `电子书由程序根据官方XML制作。`
  （位置："本丛书共收录 N 部"之后；PDF 与 EPUB 说明页一致。）
- 来源是**官方**时不加任何字。
- 文件名、封面、书签、目录页不加标签，保持干净。

## 6. 输出目录（双方可配、互不混淆）

- 官方：`cbeta_ebooks/{fmt}/{canon}/{work}.{fmt}`（现状不动；设置项 `cbeta_ebooks_dir` 不动）。
- 自制：`xml_to_ebooks_dir/{work}.{fmt}`（**完全平展**，pdf/epub 同目录，
  扩展名区分；设置项新增，可配，默认 `cbeta_ebooks_xml`）。
- 复用规则：目标文件存在 **且** 比预设文件新 → 跳过（不重生成）；
  否则生成。跳过时日志写 `跳过 T0001.pdf（已是最新）`（灰色）。
- GUI 产物识别：`{work}*.{fmt}` 匹配（如 `T0001 中論.pdf`），命中即视为已生成。
- 「已下载/已生成」检查各查各的目录；缺书提示只针对官方源（现状），
  xml 源缺文件直接走第 4 节生成流程。

## 7. 合并流程（UI 视角变化点）

1. 点「合并」→ 空书/空白改名检查（不变）。
2. 来源与预设取右栏当前选择（§1，不另弹框）。
3. 来源=官方且有缺书 → 原"是否先下载？"弹窗（不变）；来源=自制缺文件 → 直接进生成窗（不二次询问；取消=中止合并）。
4. 合成（不变；说明页带第 5 节注明）。

## 8. 不做

- per-book 来源细粒度（`work_sources` 只读兼容）。
- 单本内部更细的生成进度（对面只在完成时落一行）。
- ZIP/导出不新增弹框（沿用现状）。
- 预设目录下解析失败的 `*.json` 不进下拉框（静默跳过）。
